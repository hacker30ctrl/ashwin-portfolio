## 🛠️ How to Customize Your URLs

In `index.html`, you can update the following placeholder profile links with your exact profile URLs:

1. **LinkedIn:** Search for `https://linkedin.com` and replace with your profile URL (e.g. `https://linkedin.com/in/ashwin-sinha`).
2. **GitHub:** Search for `https://github.com` and replace with your GitHub username (e.g. `https://github.com/ashwinsinha`).
3. **LeetCode:** Search for `https://leetcode.com` and replace with your LeetCode handle.
4. **Resume:** If you have a `resume.pdf` file, place it in this folder and add a download button linked to `resume.pdf`.

## 🌐 Free 1-Minute Deployment Options

### Option A: GitHub Pages (Recommended)
1. Create a new public repository on GitHub (e.g., `ashwin-portfolio` or `ashwin.github.io`).
2. Push or upload `index.html`.
3. In repository **Settings** → **Pages** → select `main` branch → **Save**.
4. Your portfolio will be live at `https://<your-username>.github.io`!

### Option B: Netlify Drop (Instant Drag & Drop)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `ashwin-portfolio` folder.
3. It will be live instantly with a free HTTPS URL!
